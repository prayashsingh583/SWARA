Swara — A Safe, AI-Powered Case Management Platform

Swara is a secure, accessible, and responsive web application designed to support survivors and professionals through structured case management, safe check-ins, and AI-assisted insights. Built with a focus on privacy, accessibility, and informed decision-making, Swara provides role-based experiences for survivors and professionals.

Key Features

- Role-Based Access Control: Dedicated experiences for survivors and professionals.
- Secure Authentication: JWT-based authentication and protected access.
- Case Management: Structured organization and management of cases and case-related notes.
- AI-Powered Insights: Google Gemini API integration for analyzing case notes and generating actionable insights to support professionals.
- Check-In Assessments: Supports survivor check-ins and assessment workflows.
- Professional Dashboard: Data visualization and case-related insights to support informed decisions.
- Multilingual Interface: Internationalization support for a more accessible user experience.
- Responsive Design: Optimized for desktops, tablets, and mobile devices.
- Audit Logging: Records relevant system activities to support accountability.

Technology Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS v4, React Router, Recharts, i18next
- Backend: Python 3.11, FastAPI
- Database & ORM: SQLite, SQLAlchemy
- Database Migrations: Alembic
- AI Integration: Google Gemini API
- Security: JWT authentication, CORS configuration, and audit logging

Architecture

Swara follows a client-server architecture. The React frontend communicates with the FastAPI backend through APIs. The backend manages authentication, application logic, database operations, and AI integrations.

Project Objective

Swara aims to provide a safer, more accessible, and structured digital environment for survivor support and professional case management, using AI as an assistive tool rather than a replacement for human judgment.

Development Status

Developed as an innovation project for the Smart India Hackathon (SIH) internal hackathon.
